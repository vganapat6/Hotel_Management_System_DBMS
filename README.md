Hotel Management System

Project Description

This project is a Hotel Management System developed using MySQL.
It manages customers, rooms, bookings, payments and check-in/check-out details.

Technologies Used
- MySQL
- SQL
- DBMS

Database Tables
1. Customers
2. Room_Types
3. Rooms
4. Bookings
5. Payments
6. Check_In_Out

Main Features
- Customer management
- Room management
- Hotel bookings
- Payment management
- Check-in and check-out
- Automatic booking cost calculation
- SQL triggers
- Joins and aggregate queries
- Normalization
- ACID transactions

How to Run
1. Open MySQL Workbench.
2. Open `hotel_management.sql`.
3. Execute the SQL script.
4. The database and tables will be created.
5. Run the required queries.
